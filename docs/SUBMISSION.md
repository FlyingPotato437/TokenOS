# Hackathon submission copy

## One-line pitch

TokenOS is an Economic Memory Compiler that gives Raven the cheapest safe EverOS memory portfolio that preserves the right decision, with an auditable same-Raven token proof.

## Short description

Persistent Raven agents get more expensive as EverOS memory grows. Traditional retrieval optimizes for similarity; TokenOS optimizes for economic value while preserving policy and required facts. It prices each memory, models duplicates, contradictions, dependencies, and complements, then searches for the best safe portfolio under an exact token budget. A controlled A/B runs uncontrolled and governed contexts through the same Raven runtime, model, task, tools, and settings. TokenOS records token usage, safety checks, counterfactual ablations, and live-versus-replay labels in a local evidence ledger, then writes a successful agent case back to EverOS so a related future run can receive transparent historical outcome lift.
