# Hackathon submission copy

## One-line pitch

TokenOS is an agent-agnostic Economic Memory Compiler that finds the cheapest safe memory portfolio preserving the right decision. This build uses EverOS for memory and Raven as the agent execution service, producing an auditable same-runtime token proof.

## Short description

Persistent agents get more expensive as memory grows. Traditional retrieval optimizes for similarity; TokenOS optimizes for economic value while preserving policy and required facts. It prices each memory, models duplicates, contradictions, dependencies, and complements, then searches for the best safe portfolio under an exact token budget. A controlled A/B sends uncontrolled and governed contexts through the same Raven execution service, model, task, tools, and settings. TokenOS records token usage, safety checks, counterfactual ablations, and live-versus-replay labels in a local evidence ledger, then writes a successful agent case back to EverOS so a related future run can receive transparent historical outcome lift.
